# dotfiles

My Arch Linux setup, kept in `~/.config`.

- **uwc**: compositor config (binds, rules, options, monitors)
- **shell**: [ushell](https://github.com/undrscores/ushell) (Quickshell), cloned to `~/.config/quickshell/ushell`; settings in `ushell/config.json`
- **foot**, **btop**, **fastfetch**: terminal and CLI configs
- **gtk-3.0 / gtk-4.0 / qt5ct / qt6ct**: toolkit settings. The colour files in these are generated by ushell from the wallpaper palette. `qt5ct.conf` / `qt6ct.conf` are not tracked (Qt needs absolute paths); ushell creates them, then add `icon_theme=Papirus-Dark` under `[Appearance]` and a `[Fonts]` section with Geist
- **fontconfig**: Geist (UI) and Geist Mono Nerd Font (mono)

Fonts: Geist from [vercel/geist-font](https://github.com/vercel/geist-font), `otf-geist-mono-nerd` from the Arch repos.

## Zsh

Zsh lives in `zsh/` via `ZDOTDIR`. The one file that must stay in `$HOME` is `~/.zshenv`;
`zsh/zshenv.reference` is a copy of it. Its first line is `export ZDOTDIR="$HOME/.config/zsh"`.
